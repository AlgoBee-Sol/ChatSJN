# Version 0.1 implementation

One pnpm workspace: React/Vite client, Express API, shared Zod contracts. MongoDB is the source of truth. The local launcher starts a persistent development MongoDB when no URI is provided. No production seed data or fallback model.

1. Secure session authentication and resumable adult onboarding.
2. Responsive branded public site and authenticated workspace.
3. Conversation ownership, history and language/profile settings.
4. Restricted uploads, page-aware extraction, review and immutable publication.
5. Pluggable embeddings and generation, deterministic authority constraints, citation validation before delivery.
6. Integration, religious isolation and browser tests using explicitly synthetic fixtures.
7. Local operation and Cloudflare migration documentation. No deployment in this phase.

Design: SJN / a thoughtful space for Islamic learning. Ink-green, warm ivory, editorial serif headings, Urdu typography, restrained geometric details; accessible mobile drawer and explicit evidence states.
